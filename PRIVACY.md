# Политика конфиденциальности расширения «Чердак»

_Обновлено: 12 ноября 2026 г._

Расширение «Чердак — данные входа для подписки» помогает вам собрать данные входа
**с вашего собственного аккаунта** (ChatGPT, Claude, Grok/X, Cursor), чтобы вы могли
передать их сервису Чердак для оплаты подписки на ваш же аккаунт.

## Что делает расширение

- Когда вы нажимаете одну из кнопок «Скопировать…», читает **в вашем браузере** то, что
  эта кнопка называет: куки входа сайта сервиса или — для кнопки «Скопировать ID аккаунта»
  ChatGPT — страницу сессии `chatgpt.com/api/auth/session` в открытой вкладке ChatGPT.
  Из этой страницы берётся только ID аккаунта.
- Кладёт результат в **буфер обмена** вашего устройства. Вы сами вставляете его в свой
  заказ на сайте Чердака или в боте.

## Чего расширение НЕ делает

- **Не отправляет** ваши данные ни на свои, ни на любые сторонние серверы. Единственный
  запрос, который оно делает, — к странице сессии ChatGPT в его же вкладке, как это делает
  сама страница ChatGPT.
- **Не ведёт** фоновую слежку, не собирает аналитику, не отслеживает историю
  просмотров, не работает в фоне.
- **Не хранит** ваши данные: ничего не сохраняется в расширении между нажатиями.
- **Не читает** ничего за пределами перечисленных сайтов.

## Какие данные затрагиваются

Только данные входа тех сайтов, для которых расширению выданы разрешения:
`chatgpt.com`, `chat.openai.com`, `claude.ai`, `grok.com`. На `x.com` и `cursor.com`
расширение только узнаёт сервис по адресу вкладки, а данные берёт с `grok.com`.
Эти данные принадлежат вам и остаются под вашим контролем: расширение лишь
копирует их в ваш буфер обмена по вашему действию.

## Разрешения и зачем они

- **cookies** — прочитать куки входа (без него httpOnly-куки недоступны).
- **activeTab** — по вашему нажатию на значок узнать адрес открытой вкладки, чтобы показать нужный сервис.
- **scripting** — для кнопки «Скопировать ID аккаунта»: прочитать страницу сессии ChatGPT в открытой вкладке ChatGPT.
- **host_permissions** на перечисленные домены — работать только с этими сайтами.
