# Публикация в Chrome Web Store

Всё, что просит форма магазина, — здесь: файлы лежат в `store/`, тексты — ниже, их можно
копировать как есть.

## Перед первым разом

1. Зайди в [консоль разработчика](https://chrome.google.com/webstore/devconsole) своим
   Google-аккаунтом, прими соглашение и оплати регистрацию — разово $5.
2. В «Аккаунт» укажи почту для связи и подтверди её. Статус «трейдер / не трейдер» (требование
   ЕС): расширение бесплатное, но связано с магазином — честнее выбрать «трейдер» и указать
   контакты магазина.

## Новый товар

«Добавить элемент» → загрузи zip последней версии из
[Releases](https://github.com/qpsychocode/cherdak-extension/releases/latest)
(`cherdak-extension-X.Y.Z.zip`, `manifest.json` внутри лежит в корне — так и нужно).

### Вкладка «Описание в магазине»

- **Название и краткое описание** берутся из `manifest.json`.
- **Подробное описание:**

```
Чердак (shop.cherdak.org) оформляет подписки ChatGPT, Claude, Grok, X и Cursor на твой собственный аккаунт. Для этого заказу нужны данные входа в аккаунт — раньше их доставали вручную через инструменты разработчика браузера.

Расширение делает это одной кнопкой. Открой сайт сервиса, нажми на значок Чердака и выбери то, что просит заказ:
• ChatGPT — «Скопировать сессию» или «Скопировать ID аккаунта»;
• Claude — «Скопировать sessionKey», «Скопировать Organization ID» или «Скопировать все куки»;
• Grok, X и Cursor — «Скопировать токен входа» или «Скопировать все куки» (единая подписка включается на grok.com).

Данные попадают в буфер обмена — вставь их в свой заказ на сайте или в боте @cherdax_bot.

Безопасность
• Расширение ничего никуда не отправляет: читает данные только в твоём браузере и только по нажатию кнопки.
• Работает только на chatgpt.com, chat.openai.com, claude.ai и grok.com. Нет фоновой работы, аналитики и рекламы.
• Код открыт: github.com/qpsychocode/cherdak-extension

Видео — как достать данные для каждого сервиса: shop.cherdak.org/extension
```

- **Категория:** «Инструменты». **Язык:** русский.
- **Значок магазина:** `store/icon-128.png`.
- **Скриншоты** (1280×800): `store/screenshot-1-claude.png` … `screenshot-4-grok.png`.
- **Малая промо-плитка** (440×280): `store/tile-440x280.png`.
- **Официальный сайт:** `https://shop.cherdak.org`. **Поддержка:** `https://t.me/cherdax_support`.

### Вкладка «Конфиденциальность»

- **Единственное назначение:**

```
Скопировать в буфер обмена данные входа собственного аккаунта пользователя (ChatGPT, Claude, Grok) по его нажатию — чтобы он передал их в свой заказ подписки в магазине Чердак.
```

- **cookies:**

```
Данные входа (__Secure-next-auth.session-token на chatgpt.com, sessionKey на claude.ai, sso на grok.com) хранятся в куки с пометкой httpOnly — страница их не видит. Расширение читает куки только этих сайтов и только когда пользователь нажал кнопку «Скопировать…», и кладёт результат в его буфер обмена.
```

- **activeTab:**

```
По нажатию на значок узнать адрес открытой вкладки, чтобы показать кнопки нужного сервиса (ChatGPT, Claude или Grok/X/Cursor).
```

- **scripting:**

```
Только для кнопки «Скопировать ID аккаунта» на chatgpt.com: во вкладке ChatGPT читается страница chatgpt.com/api/auth/session и из ответа берётся только ID аккаунта.
```

- **Разрешения на хосты:**

```
chatgpt.com, chat.openai.com, claude.ai, grok.com — сайты, данные входа которых копирует расширение. Других сайтов расширение не касается.
```

- **Удалённый код:** «Нет, я не использую удалённый код».
- **Использование данных:** отметь «Информация для аутентификации» (расширение её читает,
  хотя и не отправляет) и поставь все три подтверждения: не продаём, не используем не по
  назначению, не для кредитных решений.
- **Политика конфиденциальности:** `https://shop.cherdak.org/extension#privacy`.

### Вкладка «Распространение»

Публичное, все регионы. Бесплатно.

## Проверка Google

Обычно от нескольких часов до нескольких дней. Расширения, которые читают куки входа, иногда
проверяют дольше и могут задать вопросы — отвечай текстами выше: ничего не отправляется, только
по нажатию, только эти четыре сайта, код открыт.

## После одобрения

1. Пришли ссылку на страницу расширения в магазине — её впишут в
   `packages/shared/src/browser-extension.mjs` (`EXTENSION_STORE_URL`), и на сайте появится кнопка
   «Установить из Chrome Web Store».
2. Чтобы новые версии уходили в магазин сами (по тегу `vX.Y.Z`, см. README): в
   [Google Cloud](https://console.cloud.google.com) включи Chrome Web Store API, создай OAuth-клиент
   (тип «Приложение для ПК»), получи refresh token и положи в секреты репозитория на GitHub
   `CWS_EXTENSION_ID`, `CWS_CLIENT_ID`, `CWS_CLIENT_SECRET`, `CWS_REFRESH_TOKEN`.
