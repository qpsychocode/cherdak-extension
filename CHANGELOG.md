# Версии

## 1.1.0

- Отдельная кнопка на каждое, что может попросить заказ. ChatGPT: «Скопировать сессию» и
  «Скопировать ID аккаунта». Claude: «Скопировать sessionKey», «Скопировать Organization ID»,
  «Скопировать все куки». Grok · X · Cursor: «Скопировать токен входа», «Скопировать все куки».
- ID аккаунта ChatGPT берётся со страницы сессии chatgpt.com во вкладке ChatGPT — отсюда новое
  разрешение `scripting`.
- Попап помещается целиком, без полосы прокрутки.

## 1.0.0

Первая версия: ChatGPT, Claude, Grok · X · Cursor; копирование одной кнопкой, у Claude —
ключ и Organization ID по отдельности; светлая и тёмная тема.
